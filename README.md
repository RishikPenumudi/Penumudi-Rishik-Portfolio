# Rishik Penumudi — Portfolio Website

A responsive, dark tech-inspired portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — all page content and sections
- `styles.css` — responsive styling and visual effects
- `script.js` — mobile navigation and profile-link placeholder handling

## Preview locally
1. Extract this ZIP.
2. Open `index.html` in a modern browser.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new public repository, e.g. `rishik-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root (not inside an extra nested folder).
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the deployment to finish. The URL will look like `https://YOUR-USERNAME.github.io/rishik-portfolio/`.

## Important: personalize before sharing
- In `index.html`, replace the LinkedIn and GitHub `href="#"` placeholders with your actual profile URLs.
- Review contact details and all achievement/certificate titles for exactness.
- Add real photos of your SAHAJ prototype and project screenshots if you have them.
- Add repository/demo links only for projects that are actually implemented.
- This website labels several items as concepts/designs where no deployed implementation was confirmed. Keep that distinction accurate.
- No third-party JavaScript libraries are required. Google Fonts are loaded from the web; system fallbacks will be used if unavailable.
