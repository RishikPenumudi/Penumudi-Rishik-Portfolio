# Rishik Penumudi — Portfolio Website

A responsive personal portfolio focused on product thinking, analytics, software projects, innovation, and certifications.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive visual styling
- `script.js` — mobile navigation interaction
- `assets/sahaj-primary.jpg` — the exact SAHAJ photo supplied in the conversation; used as the main project image
- `assets/sahaj-supporting.png` — additional prototype reference photo for the case study

## Run locally
Open `index.html` in a browser. The site uses Google Fonts when internet access is available; system fallbacks are included.

## Publish with GitHub Pages
1. Upload the files and the `assets` folder to the root of the repository.
2. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
3. Wait for GitHub Pages to finish publishing.

## Before sharing
Replace any placeholder social profile links in `index.html` with your real LinkedIn and GitHub URLs. Verify all claims and project statuses before sending the site to recruiters. The SAHAJ case study distinguishes prototype work from proposed future enhancements.
